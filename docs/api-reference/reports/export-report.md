# Export Report

Exports a previously generated report in the requested file format.

This endpoint allows users to download reports that have already been generated by the Reports API. Exported reports can be used for auditing, compliance, executive presentations, business analysis, payroll processing, and long-term archival.

Supported export formats include **PDF**, **Excel**, **CSV**, and **JSON**.

---

## Endpoint

```http
GET /reports/export
```

---

## Authentication

```http
Authorization: Bearer YOUR_ACCESS_TOKEN
```

---

# Query Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| reportId | integer | Yes | Unique identifier of the generated report |
| format | string | Yes | Export format (`PDF`, `Excel`, `CSV`, or `JSON`) |

---

# Example Request

```http
GET /reports/export?reportId=9201&format=PDF
```

---

# Response Fields

| Field | Description |
|---------|-------------|
| reportId | Unique report identifier |
| reportName | Name of the exported report |
| reportType | Type of report |
| format | Export file format |
| fileName | Generated file name |
| fileSize | Size of the exported file |
| downloadUrl | Temporary download URL |
| expiresAt | Download URL expiration timestamp |

---

# Error Responses

| Status Code | Description |
|-------------|-------------|
| 400 | Invalid request parameters |
| 401 | Authentication failed |
| 403 | Access denied |
| 404 | Report not found |
| 406 | Unsupported export format |
| 429 | Rate limit exceeded |
| 500 | Internal server error |
| 503 | Service unavailable |

# Common Use Cases

- Share reports with management
- Archive reports for compliance
- Import data into business intelligence tools
- Generate audit documentation
- Perform offline analysis
- Distribute reports to stakeholders

---

# Best Practices

- Download exported reports before the temporary link expires.
- Choose the appropriate export format for your use case.
- Protect exported reports containing sensitive employee or payroll information.
- Store reports securely to meet organizational compliance requirements.
- Regenerate reports if the download link has expired.
- Always use HTTPS when downloading reports.
