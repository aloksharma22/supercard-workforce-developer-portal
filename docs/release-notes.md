# Release Notes

This page highlights significant updates, improvements, and new capabilities introduced in each release of the **Supercard Workforce Developer Portal**.

Unlike the **Changelog**, which provides a detailed technical history of changes, the Release Notes focus on the features and enhancements that matter most to developers and API consumers.

---

# Release 1.0.0

**Release Date:** July 30, 2026

## Overview

Version **1.0.0** marks the initial public release of the Supercard Workforce Developer Portal.

This release introduces a complete developer documentation experience built using **OpenAPI 3.1**, **MkDocs Material**, and **Redocly**, demonstrating modern Documentation-as-Code practices and enterprise API documentation standards.

---

A fully responsive documentation portal built with MkDocs Material that provides a consistent and intuitive developer experience.

## Known Limitations

This portfolio project represents a demonstration of enterprise documentation practices.

The following are intentionally out of scope:

- Live production API
- Authentication server
- Production SDK packages
- Automated testing environment
